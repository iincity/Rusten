# Rusten 0.2.0

本版本将桌面界面迁移到原生 NSH，并恢复扫描、空间分析与清理的完整操作流程。

## 主要变化

- 启动后自动扫描；清理按当前选中的分类直接执行，执行前继续复核文件身份和安全条件。
- 提供淡绿色（默认）、明亮和暗黑主题，并统一标题栏、主界面和退出确认框的样式。
- 空间分析从根目录列出子目录及占用空间，支持逐级进入和返回。
- 删除桌面界面的文件恢复入口；清理不生成恢复备份。
- 修复日志、应用缓存和安装残留等分类的规则与执行链；补扫重定向的用户目录，过滤缓存索引中的已删除文件。
- 优化扫描、搜索和清理过程中的响应与进度更新。

## 下载与运行

Windows 压缩包包含 `cleaner-ui.exe`、`admin-helper.exe` 和 `cleaner-cli.exe`。解压后运行 `cleaner-ui.exe`。管理员助手必须与主程序位于同一目录，才能执行需要提权的系统清理。

清理会永久删除符合规则的文件。对回收站、休眠文件及分页文件等特殊操作，界面仍依安全策略要求确认或显示不可用状态。

## 验证

发布前执行工作区测试、严格 Clippy、Debug/Release 构建和隔离文件清理闭环。真实系统文件、用户回收站及系统存储设置未用于破坏性测试。
