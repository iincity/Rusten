# 退出确认与搜索性能回归

2026-10-31，针对 UI 迁移后的退出确认缺失、搜索和清理变慢反馈。

## 修复范围

- NSH 原生窗口增加可选关闭回调；Rusten 主程序在 WM_CLOSE 时显示所属窗口的退出确认，默认选择“否”。标题栏关闭、系统菜单与 Alt+F4 的标准关闭请求经过同一入口。
- 目录列表原先每页遍历全部文件并重新排序，地图再按 80 条连续分页，导致重复工作。改为共享排序后的目录项；索引新增文件或目录时失效，删除后重建的索引不复用旧缓存。
- 清理前分类先匹配选中路径，再构造对应记录，避免复制整个全盘文件列表。
- 普通文件清理完成不再递归查询所有磁盘的回收站；包含回收站操作的清理仍保留结果查询及清空核验。

## 本机验证

- 新增 16000 文件地图性能回归：修复前 3.468 秒并失败；修复后 33.7 毫秒并通过，核对总大小不变。
- 新增缓存回归覆盖重复读取、目录新增、硬链接、新文件大小聚合、大小写搜索与删除后的失效。
- 既有 261 文件 / 约 144 MiB 隔离清理基线 206 毫秒，无失败或跳过；完整验收继续运行相同测试。
- Debug 实际主窗口：空闲关闭提示、选择否保留窗口；扫描中关闭提示、选择否后枚举继续超过 15 万文件；再次关闭选择是后进程退出。
- 自动化工具不支持 F4，Alt+F4 未做按键实测，仅由同一 WM_CLOSE 分支覆盖。
- 全部测试、严格 Clippy、Debug/Release 构建与后续 UI 测试记录在 `target/exit-performance-acceptance.log`。
