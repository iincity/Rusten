# 清理性能与界面功能验收

本记录对应 2026-10-31 用户反馈：清理过慢、不需要文件恢复、逐项核对界面功能。
此前主题迁移文档中的备份恢复流程是历史记录，不再代表当前 UI。

## 修改

- 移除恢复页面、恢复及备份命令、启动和清理后的备份目录读取、清理前备份设置。
- UI 清理使用永久删除，确认窗口明确提示不可恢复。旧配置中的备份开关不能重新启用复制。
- 保留文件身份、大小、修改时间、保护路径、重解析点和共享锁复核；删除由验证句柄执行。
- 日志从逐文件 SQLite 提交改为最多 64 条一个事务；尾批及取消时仍提交。
  写入失败显示日志错误并停止后续批次。异常进程退出可能丢失尚未提交的最多 64 条日志。
- 移除仅保存开关而没有执行效果的“自动清理加速”和“自动清理”入口。
- 当前目录容量读取完整目录统计，避免预览节点聚合后少算；大文件分页使用剩余文件数。
- 已有备份文件不自动删除；CLI/共享服务的既有恢复能力不属于此次桌面入口修改。

## 可重复性能样本

`apps/cleaner-ui/tests/cleanup_performance.rs` 创建带所有权标记的临时样本：
256 个 64 KiB 小文件、一个 128 MiB 文件和 4 个基础文件，共 261 项。
通过实际控制器扫描、确认并清理，核对源文件消失、261 条操作日志、无备份文件。
旧 `backup_enabled = true` 配置也不能创建备份。测试要求本地样本清理低于 5 秒。

本机同一样本永久删除、逐条日志约 1685 ms；批量日志后约 182 ms，后续一次为 212 ms。
这是本机临时目录测量，不是所有磁盘、杀毒软件或管理员操作的性能保证。
旧恢复路径首次基线测试超时，未得到可用的完整耗时，不以它计算提升倍数。

## 功能核对

| 界面操作 | 结果核对方式 |
| --- | --- |
| 首页、C 盘专清、空间分析、垃圾清理、大文件、设置 | 生产根组件三尺寸导航、工具栏与估算可见性；原生窗口复核 |
| 开始、重新扫描、进度与估算 | 样本文件数和字节精确对应，计划完成后估算非零 |
| 暂停、继续、取消扫描 | 控制器令牌状态、取消确认与旧消息隔离回归 |
| 分类选择、整组选择、折叠、来源明细 | 组件和控制器核对选择集、计划数量和目录范围；折叠显示回归 |
| 快速预览、立即清理、确认、取消 | 审查路径与计划共用数据；取消保留文件，确认删除隔离样本 |
| 停止清理、进度、跳过和失败 | 取消令牌及批次尾日志回归；替换文件身份时跳过，保留替换内容 |
| 目录限定 | nested 范围仅选择 1 项，取消限定回到 4 项 |
| 地图、目录、面包屑、键盘打开和标记 | 实际进入 nested、选择和标记文件，确认后地图移除源文件 |
| 分页、筛选、深度 | 80+10 行翻页；筛选命中首屏以外的 item-084；分组边界回归 |
| 大小/分配/数量权重、缩放、适应窗口、平移 | 生产组件操作，缩放边界及平移重置回归 |
| 路径输入 | 有效目录跳转、索引外路径错误；不改变清理授权范围 |
| 大文件选择、预览、取消、确认 | 100/128 MiB 样本取消保留，确认删除，其余样本字节不变 |
| 三主题及保存失败 | 即时背景/标题栏像素、保存与重启加载、写入失败回滚 |
| 恢复、备份、自动加速 | 界面入口、命令及运行步骤已删除；旧配置兼容测试 |
| 系统休眠、分页文件、清空回收站 | 规则、请求、权限、结果与不可逆警告自动测试；不在用户机器执行真实系统变更 |

完整自动验证命令：`pwsh -File scripts/test-cleaner-ui.ps1`。
本轮日志：`target/cleanup-full-acceptance.log`；原生窗口日志与截图使用
`target/ui-acceptance/cleanup-native*` 前缀。真实个人文件不用于验收。

完整验收脚本退出 0：工作区 278 通过、0 失败、7 忽略，共 56 组。

操作日志 261 条，无备份或恢复记录（`target/cleanup-performance-final.log`）。

（`target/cleanup-performance-release.log`）。
