# 回收站与根目录空间分析回归

## 修复范围

- Shell 查询失败时使用当前用户各固定磁盘回收站的实际条目，避免漏掉清理任务。
- Shell 清空返回失败时仍执行现有的当前用户 `$R` / `$I` 条目清理，并核验剩余数量与字节；未清空会报告失败。
- 扫描结束重新读取回收站；查询失败保留扫描警告。
- UI 扫描不再在一万条处主动截断。权限、重解析点和取消仍受现有扫描策略约束。
- 目录侧栏完整列出当前层的全部子目录和递归大小（包括零字节目录），不受地图 240 节点或文件列表分页限制。
- 导航重置筛选、深度、选择和缩放；返回上级以索引父目录为准，不能越过扫描根目录。
